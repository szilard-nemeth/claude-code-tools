# claude-code-tools

## Pull requests

PR bodies follow `.github/pull_request_template.md` (What / Why, How to review, Testing done). Fill every section; there is no test suite, so "Testing done" lists the manual scenarios run and their results.

## Git

The repo has no local `user.name` / `user.email`, and there is no global one on this machine. Commit as `git -c user.name=nemethszyszy -c user.email=szilard.nemeth88@gmail.com commit ...`.
